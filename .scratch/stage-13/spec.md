# Спека: Этап 13 — Storybook (плейграунд компонентов)

Гриллинг 2026-11-18, Q7/Q8/Q12/Q13/Q14, пользователь подтвердил сводку. Реализация **после этапа 12**. Цель: изоляция состояний UI-компонентов, визуальный плейграунд, a11y-проверка на уровне стори (продолжение WCAG-линии §7).

## Решения гриллинга

| Q   | Решение                                                                                                                                                                                                                                                                                                                                                              |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Q7  | **Storybook 10 + `@storybook/nextjs-vite`** — единственный актуально поддерживаемый фреймворк для Next 16 (webpack-вариант legacy); Tailwind v4 нативно через `@tailwindcss/vite`. Известные ограничения: React Compiler и RSC в SB не запускаются — стори только для клиентских компонентов; next/font (Geist) может потребовать фолбэка в preview — риск тикета 01 |
| Q8  | Слайс 1 = презентационные компоненты на мок-пропах + addons: **a11y (axe)** на каждую стори, **theme-toolbar** light/dark (next-themes-декоратор, обе темы равнозначны — §1)                                                                                                                                                                                         |
| Q12 | Ко-локация: `*.stories.tsx` рядом с компонентами в `src/components/shop/` (автоподхват glob'ом в main.ts); конфиг `.storybook/` в корне; Biome/tsc покрывают автоматически                                                                                                                                                                                           |
| Q13 | Слайс 2 = интерактивные с моками: cart-interactive/promo-block (мок-action'ы через пропсы-колбэки — правка прод-кода допустима малой кровью: инъекция зависимости с дефолтом = текущее поведение), checkout-form (инъекция onSubmit с дефолтом), order-tracker (мок fetch). **support-chat вне скоупа** (мок WS-релея дорог; живой путь покрыт чат-e2e этапа 12)     |
| Q14 | Визуальные регресс-снапшоты — **отложены до редизайна** (флап шрифтов/антиалиасинга Win vs Linux)                                                                                                                                                                                                                                                                    |

## Слайс 1 (презентационные)

counter (min/max дизейблят кнопки, size sm/default, announceValue), status-badge (все 9 статусов — цвета токенов --status-info/progress/success + destructive), price-line (зачёркнутая старая цена), order-totals (все варианты: скидка есть/нет, доставка платная/бесплатная), promo-card, product-card (мок-пропы: цена, скидка, emoji-фолбэк), menu-nav, footer, copy-link-button, add-to-cart-button (состояния добавления).

## Слайс 2 (интерактивные)

cart-interactive (степперы/удаление на useOptimistic — мок-action'ы колбэками), promo-block (применение/снятие, причины неприменимости), checkout-form (inline-валидация: ошибки полей, aria-invalid), order-tracker (мок fetch API: смена статуса по клику «тик» в стори).

## Вне скоупа

support-chat (WS), серверные компоненты (header/footer-слоты с RSC-чтениями — стори только клиентским частям), визуальные снапшоты (Q14), addon-vitest coverage, деплой SB как сайта (chromatic/gh-pages — roadmap при необходимости).

## Готово, когда

- `pnpm storybook` поднимается, все стори рендерятся в обеих темах; axe-нарушений по стори слайса 1 нет (или задокументированы с обоснованием); `pnpm build-storybook` проходит; `pnpm build`/lint/tsc не сломаны; AGENTS §2/§3/§6 обновлены
