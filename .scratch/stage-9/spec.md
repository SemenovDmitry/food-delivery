# Этап 9 — Оплата. Спека

Дата: 2026-11-17. Контекст: MVP-арка (этапы 0–7) закрыта и верифицирована; этап 9 — первая из трёх финальных фич (оплата → уведомления/автоджоба → ops-харднинг). ## Поток (канонический)

1. **Чекаут**: radio «Онлайн-оплата / При получении», дефолт — «При получении»; «Онлайн-оплата» видна при ≥1 активном провайдере.
2. **`createOrder`**: ревалидация способа; онлайн → заказ (`created`, `pending`) + `provider.initiate` (externalId) + строка `payments` (amount = subtotal − скидка + доставка) → redirect на pay; «при получении» → прежний поток, payment-строки нет.
3. **Pay-страница** `(provider)/orders/[id]/pay`: шаг 1 — «Выберите банк» (активные провайдеры) + отсчёт 5:00 от `orders.createdAt`; шаг 2 — заглушка банка («Оплатить» / «Отмена»).
4. **Confirm** (`POST /api/payments/mock/confirm`, доступ владелец/uuid): пишет `payments.provider` = банк, `status = processing`, новый externalId; подписывает payload HMAC и **loopback-POST'ит** webhook; ответ → redirect на трекинг.
5. **Webhook** (`POST /api/payments/mock/webhook`): `verifyWebhook` (HMAC-SHA256 по сырому телу, `timingSafeEqual`) → общее ядро `applyPaymentEvent` (идемпотентные переходы, 409 на отменённый, TTL-гард → `cancelled_by_timeout`) → `revalidateTag('orders', 'max')`.
6. **Трекинг**: чип «Оплачено» доезжает поллингом ≤25 c (`paymentStatus` уже в DTO).

## Архитектура

```
Браузер          /api/payments/mock/confirm        /api/payments/mock/webhook
   │ (банк:          «бэкенд провайдера»          «приём платежки»
   │  Оплатить)         │                             │
   ├──────────────────▶ │ payments.provider=сбер,     │
   │                    │ status=processing           │
   │                    │ payload + HMAC-SHA256       │
   │                    │ fetch(origin) ────────────▶ │ verifyWebhook:
   │                    │                             │  подпись? TTL? отменён?
   │                    │ ◀──────── 200/4xx ──────────┤  → payment: paid|failed
   │ ◀── {redirectUrl} ─┘                             │  → orders: paid
   │ router.push(трекинг)                             │  → revalidateTag('orders','max')
```

- `lib/payments/types.ts` — интерфейсы; `mock.ts` — MockProvider (initiate: `mock_<uuid>` + redirectUrl); `index.ts` — фабрика по env (fail-fast внутри вызова); `hmac.ts` — sign/verify; `webhook-core.ts` — `applyPaymentEvent` (общее ядро для HTTP-роута; ядро не делает HTTP).
- Сумма платежа = subtotal − discountAmount + deliveryFee (всё уже посчитано сервером в `createOrder`).
- Проверка «чужой ли payment/order» в confirm — по доступу страницы (владелец или знание uuid; гость платит свой заказ по ссылке).
- Тачпоинты env: prod-compose += `PAYMENTS_WEBHOOK_SECRET` (dev-заглушка), `PAYMENT_WINDOW_MINUTES=5` (§5.32).

## Данные и миграция (drizzle-kit, SQL в git)

- `orders.paymentMethod` — text NOT NULL default `'on_receipt'` (старые заказы остаются валидными).
- `payments` — `unique(order_id)`: одна строка на заказ (Q2).
- таблица `payment_methods`: `id` uuid pk, `code` text unique (`sber`/`unionpay`), `label` text («Сбербанк», «UnionPay»), `is_active` boolean default true, `position` integer, `created_at`.
- `ORDER_STATUSES` += `cancelled_by_timeout` — миграции не требует (text-колонка + TS-константа); тачпоинты: `TERMINAL_STATUSES`, `STATUS_LABELS` («Отменён: не оплачен»), `StatusBadge` (destructive-токен), чипы `/admin/orders` (проверить: выводятся ли из констант), текст баннера отмены на трекинге, GLOSSARY (готово при спеке).
- Сидер: идемпотентно `sber` + `unionpay`, оба активны.

## Готово, когда

- «Онлайн-заказ → выбор банка → заглушка → loopback-webhook (HMAC) → „Оплачено“ на трекинге ≤25 c» — сквозной сценарий против prod-стека.
- «Отмена» на банке → payment `failed` → повтор → paid; failed-ветка проверена UI-кликом.
- Просрочка окна (SQL-сдвиг `created_at`) → pay возвращает отказ → заказ `cancelled_by_timeout` + событие; повторная оплата невозможна.
- Неоплаченный онлайн не стартует кухней (select disabled + action возвращает ошибку); после оплаты — идёт.
- `on_receipt` при `delivered/picked_up` → `paymentStatus=paid`; выключение обоих провайдеров убирает «Онлайн-оплату» из чекаута мягко.
- curl-негативы: 400 (кривой HMAC), 404 (чужой payment), 200 идемпотентный replay, 409 (отменённый заказ).
- lint / tsc×2 / build / docker build / prod `up -d --build` зелёные; возврат dev (§5.26); артефакты — `.scratch/stage-9/screenshots/`; чекбоксы §6 отмечены, §3 обновлён; коммит без push.
