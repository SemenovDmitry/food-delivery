# 05: Модалка товара (intercepting) и fallback-страница

**What to build:** клик по товару с главной открывает модалку без перезагрузки и без потери позиции скролла; прямой URL `/product/[id]` открывает полноценную страницу товара.

**Blocked by:** 04

**Status:** ready-for-agent

- [x] Intercepting route (`@modal`) перехватывает `/product/[id]` с главной → модалка товара; закрытие возвращает на главную с сохранённой позицией скролла
- [x] Fallback-страница `/product/[id]` + generateMetadata (название/описание товара)
- [x] product-details: два режима — asDialog (закрытие через router.back()) и страница; степпер количества
- [x] Несуществующий id → not-found
- [x] Клавиатурность модалки: фокус-ловушка Dialog, закрытие по Esc; a11y-чек-лист модуля
