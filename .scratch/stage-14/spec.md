## Сценарии приёмки

1. Клиент отменяет оплаченный онлайн-заказ (P3 e2e-паттерн: онлайн-оплата → cancelOrder) → статус «Отменён клиентом» + баннер «…Средства вернутся на счёт» + чип «Возвращено»; БД: payments.status=refunded, orders.paymentStatus=paid (деньги списывались), событие отмены.
2. Админ отменяет оплаченный (created) → `cancelled_by_vendor` + refund (БД-верификация).
3. Идемпотентность: replay webhook `refunded` → duplicate; `refunded` на pending → 409.
4. on_receipt-оплаченный (delivered) — отмена невозможна (карта статусов) — гвард прежний.
5. Провайдер без refund-метода → отмена оплаченного отклоняется читаемой ошибкой (шов-тест).
6. Full cycle: lint/tsc×2/build + юниты + e2e 11/11 + Storybook-аудит.
