## Comments

- 2026-11-18 (реализация): **гонка server actions** — «В корзину»/степпер optimistic, а `page.goto` сразу после клика обгоняет action (корзина пуста на /cart). Правило: после мутаций ждать серверный коммит через sr-only бейдж Σqty («В корзине N товаров») до следующей навигации/мутации. P2-3 дополнительно: применить промо только ПОСЛЕ коммита setQty — applyPromoCode/ревалидация считает по БД-корзине (qty=1 дал бы −68 ₽, не −136 ₽).
- Карточка акции показывает **имя** («−20% на всю шаурму»), не код; строка тоталов — «Скидка (имя)»; у «Классической» 340 ₽ (не 300) — числа сверены с сидером и прецедентом этапа 1.
- §5.39-дополнение: sr-only live-регионы («Текущий статус: …») имеют bounding box → «visible» для Playwright — рядом с бейджами ассерты с `exact: true`.
- Форма чекаута не самозаполняется нигде (гость) — в каждом сценарии с чекаутом fill Имя/Телефон/Адрес перед «Оформить заказ».
