**What to build:** `e2e/p2-core.spec.ts` (Q10). Сценарии: (1) **вход демо-клиента через UI** — /login: телефон `+7 999 000-00-03` → SMS-код `1111` (заглушка в notifications/консоли) → редирект /orders, бейдж сессии в шапке («Профиль» вместо «Войти»); нормализация `89990000003` → тот же вход (§ lib/phone). (2) **админ-статус → живой трекинг** — adminContext (helper 02) открывает /admin/orders, меняет статус created→preparing инлайн-select'ом; параллельно клиент-контекст держит открытой /orders/[uuid] → бейдж сменился на «Готовится» **≤ 35 с без перезагрузки** (expect с timeout 35_000, Q5; перезагрузку не звать). (4) **SECRET15** — скрытый промокод НЕ виден: блок акций /cart (только 3 публичные), лента «Акции недели», GET /api/promotions (response без SECRET15); применяется вводом кода в поле на /cart → скидка 15% на весь заказ появляется. (5) **отмена клиентом** — заказ created → /orders/[uuid] → кнопка отмены → Dialog role=alertdialog → «Подтвердить» → баннер отмены ВМЕСТО таймлайна (этап 4-бис) + бейдж destructive «Отменён клиентом»; повторная отмена кнопкой невозможна (кнопка скрыта).
