# 03: Страница /cart — редактирование

**What to build:** Двухколоночная страница редактирования корзины: степперы и удаление с optimistic-обновлением, Tabs доставки/самовывоза (локальное состояние), полные тоталы с подсказкой о бесплатной доставке, переход к оформлению с передачей fulfillment.

**Blocked by:** 02

**Status:** resolved

- [x] `lib/cart.ts`: helper `getCartForRead()` — сессия → корзина по userId, cookie `cart_id` → корзина, иначе null; **не создаёт** корзину и не пишет cookie (создание — только в actions)
- [x] `(shop)/cart/page.tsx` + CartView: строки корзины из БД (emoji-фолбэк, цена × qty, снапшот-актуальные цены), степперы `useOptimistic` + `setQty` (min 1, max 99 — MAX_QTY), кнопка удаления ×; при pending — мгновенная реакция
- [x] Пустая корзина → карточка «Корзина пуста» + кнопка «В меню» (helper из getCartForRead null/empty)
- [x] Tabs «Доставка / Самовывоз» — локальное состояние страницы (в БД не пишется); влияет на строку доставки и подсказку
- [x] Тоталы: Товары (Σ) / Скидка (calcDiscount активного промо, если применимо) / Доставка (0 | 199 ₽ | «бесплатно») / Итого = товары − скидка + доставка; в `aria-live="polite"`; подсказка для delivery: «Добавьте товаров на X ₽ до бесплатной доставки» или «Доставка бесплатная» (порог от суммы товаров до скидки)
- [x] Кнопка «Перейти к оформлению» → `/checkout?fulfillment=<выбор Tabs>`; disabled при пустой корзине
- [x] Раскладка: desktop — список слева + sticky-карточка тоталов справа; mobile — одна колонка, тоталы над кнопкой
- [x] A11y §7: степперы — aria-label («Убрать одну», «Добавить одну», «Удалить»), focus-visible, только CSS-токены
